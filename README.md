# Bellabeat Case Study

## Google Data Analytics Professional Certificate

### Project Overview

This project analyzes Fitbit fitness tracker data to identify trends in smart device usage and provide marketing recommendations for Bellabeat.

## Business Task

Analyze smart device usage data to answer:

- What are the trends in smart device usage?
- How could these trends apply to Bellabeat customers?
- How can these insights improve Bellabeat's marketing strategy?

## Dataset

Fitbit Fitness Tracker Data (CC0 Public Domain)

https://www.kaggle.com/datasets/arashnic/fitbit

## Key Findings

- Users who take more steps burn more calories.
- Sedentary time remains high despite regular activity.
- Sleep tracking is inconsistent.
- Weekday activity is generally higher than weekend activity.

## Recommendations

1. Promote personalized step goals.
2. Improve sleep tracking engagement.
3. Encourage users to reduce sedentary time.
